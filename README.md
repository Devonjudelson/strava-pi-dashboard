# Strava Pi Dashboard

A Raspberry Pi dashboard that displays live running data using the Strava API.

## Features

- Today's run(s)
- Interactive route map using Open Street Map
- Weekly mileage (day to day and week to week)
- Shoe mileage with progress bar 

## Tech Stack

- Python
- Flask
- Strava API
- HTML/CSS/JavaScript
- Raspberry Pi 4
   - With 2.4" RPi LCD screen
