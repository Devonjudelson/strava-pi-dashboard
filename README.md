# Strava Pi Dashboard

A Raspberry Pi dashboard that displays live running data using the Strava API.

## Planned Features

- Today's run(s)
- Interactive route map using Open Street Map
- Weekly mileage
- Shoe mileage
- Touchscreen interface 
- Raspberry Pi kiosk mode (maybe)

## Tech Stack

- Python
- Flask
- Strava API
- HTML/CSS/JavaScript
- Raspberry Pi 4
